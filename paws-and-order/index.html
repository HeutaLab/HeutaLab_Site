Three levels, two subjects

Characters

TipAsk for just “a police officer for a comic” and image tools often give you a shiny, realistic picture. Add the style in words (hand-drawn, thick wobbly outlines, flat bright colours) and it flips to a real comic look.

Level 1

One character portrait. Plain background, one pose, one face, like a character reference sheet.

Level 2

The same character in a place. A shared paragraph describes them, and you copy it word for word.

Level 3

A story of three or more pictures. Plan the shots with an AI partner before you make anything.

Places

TipAsk for “a police station office” and some tools fill it with people, speech bubbles and a whole scene. For an empty room, say so: no characters, no words, no speech bubbles, no captions.

Level 1

One empty room, as a wide shot.

Level 2

Two rooms that must feel like one building. Copy the shared paragraph exactly, and give each room its own layout line.

Level 3

A place sheet: several shots of one street with the same time of day, weather and colours.

      Grown-ups

      Set up the helper

      The prompt helper uses an AI service. You choose the service and use your own key, so nothing goes through anyone else’s account. The key stays in this browser and is only ever sent to the service you pick.

      Anything that speaks the OpenAI style of chat, such as LM Studio or Ollama on this computer. It must allow requests from a web page (look for a “CORS” setting).

      Raise it as the class is ready. This is set for this browser only.

      Good to know

      • Whatever a child types (their description, their idea, pasted text in the check) goes from this browser to the AI service you chose. Nothing is stored or seen by us. Check that service’s rules for children’s data.
      • Use a key with a low spending limit. Anyone who can open this browser’s developer tools on this device can read a saved key.
      • The helper is told to keep everything friendly and to invent original characters, and a few adult words are blocked. It is a backstop: a grown-up should still be in the room.
      • It only writes text prompts. Most image tools ask users to be 13+ or use a school account, so a grown-up should run those.
