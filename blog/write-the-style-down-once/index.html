Write the Style Down Once.

10 November 2026

Getting NotebookLM slides to keep one look from lesson to lesson, and fixing the ones that come out wrong.

This first went out as Edtech Tuesday #40, a weekly newsletter for teaching staff, on 10 November 2026. Lightly edited for the blog.

The short version. Ask Gemini to turn a look you like into a written style guide. Keep it as a Word doc in OneDrive and add it as a source in every NotebookLM notebook, so each deck starts from the same rules and lesson eight matches lesson one. NotebookLM’s PowerPoint download is still pictures, not text. PowerPoint’s Export turns it into one folder of slide images, and Canva’s Magic Layers makes the faulty ones editable. Rather watch than read? The full 15-minute video walkthrough is at the end.

Why doesn’t lesson two look like lesson one?

If NotebookLM gave you one good-looking deck, how do you get the same look for the next lesson, and the one after that?

The look drifts because every deck starts from a fresh description. When the description is a document you reuse, rather than words you retype, every deck starts from the same place.

In Nothing on the Slide Is Text (#38), a style guide gave one unit its look. This issue makes that style repeatable across a unit and gets the slides into Canva faster.

The #38 video was the short version, at 4 minutes. This issue’s video is the full rundown of the features, at 15 minutes. I made it because so many people at AIFE didn’t know NotebookLM could produce consistent, repeatable slide styles from style prompts written by Gemini.

NotebookLM is now called Gemini Notebook, renamed on 16 July. It’s the same product at the same address, so I’ve kept the old name here.

1. Get Gemini to write the style down

Start with something you can see: a mood board, a poster, a book cover or one slide you already like. Using a mood board to set a theme was one of the ideas people took away from my AIFE workshop.

Upload the image to Gemini and paste this:

Describe the visual style of this image as a style guide for a slide deck. Plain text only. Include:
- the background colour and 2 or 3 accent colours, as hex codes
- one heading font and one body font, named Google Fonts only
- how headings, text and images are laid out on a slide
- the style of illustration or imagery
- three things the slides must never do
Keep it under 200 words.

Try to name real Google Fonts rather than “a bold sans-serif”. Canva carries the common Google Fonts, so any text you fix later matches the rest of the slide.

Save the answer as a Word Doc in OneDrive or your desktop with a plain name, such as “!Style guide: Y6 Film”. That doc is now the house style for the unit.

2. Make the style guide a source, not a prompt

  1. In NotebookLM, upload the style guide Word doc as a source, next to your lesson material. Uploaded files don’t update themselves, so after you edit the style guide, upload it again to each notebook and delete the old copy. Decks you have already made stay as they were.
  2. In Studio, open the customise option (the pencil) on Slide Deck. Tick only two sources: the style guide and one lesson.
  3. Paste the style guide text into the prompt box as well, so it works as both material and instruction.
  4. When a deck comes out right, open the three-dot menu next to its title and choose View custom prompt. Copy that prompt into the bottom of your style guide doc. That is the wording to reuse for every other lesson.
  5. If a few slides need changes, use Revise and write instructions on all of them before you generate. Each revision makes a whole new deck and revisions are limited, so do it in one pass.

3. One PowerPoint in, one folder out

NotebookLM’s PowerPoint download looks editable but isn’t: each slide is a single picture. What PowerPoint adds is a quick way to turn the whole deck into separate images.

  1. In NotebookLM, open the deck’s three-dot menu and choose Download PowerPoint (.pptx).
  2. Open the file in PowerPoint.
  3. On Windows: File > Export > Change File Type > PNG, then Save As and choose All Slides.
  4. On a Mac: File > Export, set File Format to PNG, and choose Save Every Slide.
  5. You now have one folder with one image per slide, numbered in order.

Choose PNG over JPEG. The text stays sharper, which gives Magic Layers a cleaner picture to read.

4. Fix only what needs fixing in Canva

  1. Upload the images from the folder to Canva. You can select them all at once.
  2. Start a presentation design and put each image on its own page.
  3. Select a slide with a fault, choose Edit, then Magic Layers. Canva splits the picture into separate pieces: text, shapes and images you can edit.
  4. Fix the usual faults: clipped or hidden headings, repeated text, stray decoration and spelling.
  5. Present from Canva, or download as PowerPoint or PDF.

Slides with nothing wrong can stay as pictures. Magic Layers is only for the ones that need it.

Something to try this week

One style guide, two lessons

Pick one unit. Make one style guide, then use it to make decks for two different lessons and put them side by side. If they look like they belong together, the style guide is doing its job.

The small print

  • Pupils can use NotebookLM on Education accounts if the school switches it on for them, with stricter content rules for under-18s. Slide Decks are the exception: Google’s help page says they are only available to over-18s, so this workflow is for staff.
  • NotebookLM also doesn’t touch your Google Drive while it works (it can pull from it, but currently it doesn’t write to it) so our school Microsoft restrictions don’t apply.
  • Google’s own help page warns that slide decks can contain visual or factual errors. Check the facts, not just the fonts.
  • Public sharing of decks is switched off on Education accounts. Share the downloaded file instead.
  • Magic Layers takes PNG and JPG files, not PDFs. It works best on graphics and illustrations; photo-like images give mixed results.
  • You may read about a new step that lets you check a deck’s outline before it renders. Google lists it for Google AI Ultra only, so don’t expect it on a school account.
