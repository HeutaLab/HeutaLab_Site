Ollie · Started summer 2026

A library assistant that teaches children how to ask

Ollie is a learning assistant for the primary school library, for children aged five to eleven. It is not a search box. It is a way of teaching children how to ask — prompting as a taught skill, in the way library skills used to be taught — and a thinking partner that hands the turn back to the child rather than closing the subject. The language model runs on the iPad itself, so nothing a child says or types is sent to a cloud service. No login, no account, nothing stored per child, and the session clears at the bell.

Four screens, one owl growing up

  • Owl Buddy (ages 5–7). Voice only, nothing to read, three short sentences back and an “I wonder…” the child could go and do.
  • Ollie’s Library (ages 7–9). The child reads and types, the school’s own shelves come into the answer, and a badge says whether a real book backs it up.
  • Nexus Library Desk (ages 9–11). The child as researcher: a query console, sources, the matching shelf, and an Inspect prompt button that shows exactly what the model was told.
  • Prompt Lab (ages 9–11). The core of the product. Six rounds, six prompting skills, and a coach that marks the prompt, never the answer.

Where it stands

The four screens are designed and running in a browser rig at iPad width, which is where the screenshots come from. Inside the iPad app the same screens call the on-device model through a bridge. Still being built: the teacher-reviewed canon of common questions that is matched before the model is asked at all; the import of a real library catalogue so the shelves are the school’s own; and the tuning of speech in and out for a noisy library.

Where it will live: Ollie’s address will be ollie.heutalab.com. There is nothing at that address yet. When there is something to open, this page and that address will both say so, and Ollie will leave this page for the front of the site.

What would help

If you run a primary library, or teach in one of these year groups, two things would help enormously: the questions your children actually ask, misspelt and half-formed, because those are what the reviewed canon should be built from; and the moment you would want Ollie to refuse, or to hand a child back to you.

How this page works

On, and then off

Something appears here when there are real screens to show and a school it is being built with. It stays while it is being made honest for a real classroom rather than a demonstration. It leaves when it is something you can open: at that point it gets its own page, a place in the apps section, and a launch post on the blog.
